# makefile-lessons

Учебные примеры к курсу «Makefile с нуля» на сайте fkn.ktu10.com:
https://fkn.ktu10.com/?q=node/11423

## Как заниматься

Каждая папка `lessonNN-*` — самостоятельный пример одного урока.
Зайдите в папку урока и запускайте команды, например:

```bash
cd lesson01-hello
make hello
```

## Уроки

1. `lesson01-hello` — первая цель и рецепт, TAB vs пробелы
2. `lesson02-targets` — несколько целей, цель по умолчанию, справка `help`
3. `lesson03-quiet` — символ `@` и «тихий» вывод
4. `lesson04-variables` — переменные
5. `lesson05-reuse` — переиспользование команд через переменные
6. `lesson06-deps` — зависимости: одна цель после другой
7. `lesson07-args` — параметры командной строки, значение по умолчанию
8. `lesson08-generate` — генерация конфига из переменных (`>`, `>>`, `clean`)
9. `lesson09-colors` — цветной вывод и `export`
10. `lesson10-file-target` — цель-файл: make сам отслеживает изменения
11. `lesson11-project` — финальный проект: сборка конфига из частей
